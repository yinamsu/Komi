3. Core Features Spec for Doctors

1) Fitzpatrick Skin Passport & Energy Calibrations

Many international patients have skin of color (Fitzpatrick Types IV-VI) but local generic clinics apply high settings designed for light skin types, resulting in severe burns. KOMICARE's diagnostic quiz outputs a Skin Passport telling the patient to request custom low-pulse energy calibrations, shifting liability away from you by encouraging cooperative clinical consultations.

2) Receipt Privacy Tax Masker

Boutique clinics fear review platforms because competitors or aggressive patients leave fake reviews or extort refunds. To safeguard our partner network, KOMICARE's review validation is encrypted. The client-side masking system blurs tax refund barcodes, minute timestamps, and receipt serials, preventing clinics from identifying the reviewer while guaranteeing the authenticity of the checkout review.

3) Dynamic Star Rating Filters

We map reviews across 12 medical-centric categories. For example, instead of a simple 5-star rating, doctors are evaluated on Honest Treatment (no sales push/overtreatment) and Doctor Explanation. This highlights the premium nature of boutique clinics compared to assembly-line competitors.

3. 의료진 관점의 핵심 기능 사양

1) Fitzpatrick 피부진단 패스포트 & 시술 파라미터 유도

외국인 환자는 Fitzpatrick 피부 유형(피부톤이 어두운 IV-VI형 등)이 다양함에도 불구하고, 일부 공장형 의원에서는 동양인 기준의 강한 에너지를 일괄 조사하여 색소 침착(PIH)이나 화상 사고를 초래합니다. 코미케어의 진단 퀴즈는 원장님께 전달할 **스킨 패스포트**를 발급해 환자가 시술 전 의료진과 적절한 펄스폭 조정을 사전에 상담하도록 유도하여 부작용 합의금 분쟁을 예방합니다.

2) 영수증 개인정보 마스킹 블러 엔진

악성 블랙컨슈머가 영수증 시각, 승인번호 등을 무기로 병원을 협박하거나 경쟁 의원에서 평판 깎아내리기를 유도하는 것을 방지하기 위해, 코미케어는 결제 영수증의 유니크한 환급 바코드와 시각 단위를 웹 브라우저 단에서 마스킹(블러 처리)하여 업로드하도록 안내합니다. 환자의 병원 내 특정은 원천 방지하면서 실제 내원 이력은 철저하게 검증합니다.

3) 12개 메디컬 중심 리뷰 세부 카테고리

코미케어의 평점 필터는 단순 별점이 아닙니다. `의사의 상세한 설명`, `정직한 진료 (과잉진료 유도 안함)`, `시술 후 애프터케어 만족도` 등 **실제 의학적 전문성과 의료 윤리를 점수화**합니다. 상담 실장의 실적 강요나 공장식 회전율이 아닌, 원장님의 정직한 진료 철학이 필터 점수를 통해 환자에게 직접 도드라지게 설계되어 있습니다.

3. 医師の観点から見た核心機能仕様

1) Fitzpatrick皮膚診断パスポート＆施術パラメータ調整の誘導

海外患者はFitzpatrick皮膚タイプ（肌トーンが暗いIV-VI型など）が多様であるにもかかわらず、一部の工場型クリニックでは均一な強いエネルギーで照射し、色素沈着（PIH）や火傷を引き起こすケースがあります。KOMICAREの自己診断は**スキンパスポート**を発行し、患者が施術前に医師とパルス幅や出力の調整について事前に相談するよう促し、副作用トラブルを未然に防ぎます。

2) 領収書個人情報マスキングエンジン

悪質なレビューや競合他院による誹謗中傷からクリニックを守るため、KOMICAREは決済領収書のユニークなタックスリファンドバーコードや時間情報をブラウザ上で自動的にマスキング（ぼかし処理）してアップロードさせます。これにより、患者の個人特定を防ぎつつ、実際の来院履歴のみを厳格に検証します。

3) 12のメディカル重視レビューカテゴリ

KOMICAREの評価システムは単なる星評価ではありません。「医師の丁寧な説明」「正直な診療（過剰診療なし）」「アフターケア満足度」など、**実際の医学的専門性と医療倫理を数値化**します。カウンセラーによるアップセルや流れ作業のカウンセリングではなく、院長の誠実な診療姿勢が際立つ設計になっています。

4. System Architecture & High Performance

KOMICARE is built as a highly performant Jamstack application leveraging Vercel Edge Cache networks. 

[Client Browser] 
    │
    ├── (Reads Static HTML/CSS/JS) ──> Vercel Edge CDN
    │
    ├── (GET /api/clinics) ──────────> Vercel Serverless Function ──> Supabase DB
    │
    └── (POST /api/submit-clinic) ───> Vercel Serverless Function ──> Supabase DB

Serverless API Layer: Implemented in Node.js, routing database transactions securely to prevent direct client access to administrative tables.

4. 시스템 아키텍처 및 보안

코미케어는 글로벌 환자들의 접속 환경을 고려하여 지연 시간(Latency)을 최소화하도록 Vercel Edge CDN 인프라 위에 빌드되었습니다. 

[글로벌 환자 / 원장 브라우저] 
    │
    ├── (정적 리소스 로드) ──────────> Vercel Edge CDN (캐싱)
    │
    ├── (GET /api/clinics) ──────────> Vercel Serverless ──> Supabase DB
    │
    └── (POST /api/submit-clinic) ───> Vercel Serverless ──> Supabase DB

서버리스 API 보안: Node.js 기반의 API 라우터는 프론트엔드에서 수파베이스 DB 비공개 키(service_role) 노출을 철저히 격리하며, 도메인 검증 및 CORS 헤더를 통해 무단 타사 크롤러와 데이터 유출을 강력 차단합니다.

The backend uses a standard PostgreSQL database schema. Key relational column schemas are detailed below.

Field Type Role
id SERIAL (PK) Auto-incrementing unique registration key.
name TEXT Clinic name string.
doctor_type TEXT dermatologist, specialist, or gp.
experience_years INTEGER Clinical experience in years. Default is 7.
sleep_anesthesia BOOLEAN Indicates sleep anesthesia capabilities.
